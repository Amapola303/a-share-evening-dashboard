# A股资金面电脑手机双端看板

在线地址：https://amapola303.github.io/a-share-evening-dashboard/

## 页面能力

- 顶部日期下拉菜单切换已归档交易日，整页八个模块同步刷新。
- 覆盖总量与量能、市场宽度与连板、两融、行业/个股主力资金、龙虎榜、核心宽基ETF、宏观流动性和次日情景。
- 龙虎榜按证券与当日/3日窗口去重，机构净买入和净卖出各展示前20只。
- 手机与电脑浏览器自适应，无需本地电脑运行。
- 页面“实时刷新页面数据”按钮会跳转到最新交易日，并无缓存读取最新已发布云端快照。

## 云端更新

- 北京时间每个A股工作日 11:45 抓取午间快照。
- 17:30 抓取收盘初版，尚未披露的数据明确标为待更新。
- 19:00 抓取晚间完整版，优先补齐龙虎榜完整分页表。
- 同日快照写入 `docs/data/YYYY-MM-DD.json`，日期索引自动更新。
- 若行情日期与目标日期不一致（休市或接口异常），不会把旧行情写成当日数据。
- 两融、ETF份额与宏观指标按各自真实披露日展示；无法取得稳定增量时保留最近可得日期并明确标注。
- 指数使用东方财富盘后行情并尝试以腾讯行情作独立核验；主力资金采用平台算法口径。

数据来自公开网络行情、涨跌停/炸板池、两融与交易公开信息。缺失项不猜测、不以0代替。仅供研究，不构成投资建议。
